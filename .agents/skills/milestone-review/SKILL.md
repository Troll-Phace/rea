# Milestone Review

Read the relevant phase dependencies and issue tier. Put correctness blockers ahead of work that depends on them. Recommend a bounded fix-now batch or explain deferral; do not start an unsolicited backlog sweep.

Report scope, dependency order, acceptance criteria for the batch, and any tier ready for authorized closure. A tier is not closed simply because its code changed.
