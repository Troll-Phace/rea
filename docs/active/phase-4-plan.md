```ts
{
  is_in_delay_slot: boolean | null;

  addresses: string[] | null; // complete measured ordered slot list, or unknown
}
```

Omission supports prior captures/other providers. A new Ghidra response always supplies the object. For a nondecoded address all three values are null. For a decoded instruction, use `Instruction.isInDelaySlot()` and `getDelaySlotDepth()` directly. Depth zero is observed absence, with `addresses: []`; it is not unknown.
