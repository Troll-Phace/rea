# Interface design for PSX support

No graphical frontend is in scope. Preserve REA's existing CLI/MCP contracts and tool-design.md principles. Report unsupported format, missing/incompatible PSX loader, malformed source, unavailable memory and cancelled analysis distinctly. Error guidance must identify the needed local prerequisite without installing it. Stable format/architecture names, source hashes and explicit limitations must agree across CLI, MCP, evidence and snapshots. See PLAN.md for exact proposed contracts.
